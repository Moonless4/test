Font: A Iranian Sans — Regular
Internal family name: "A Iranian Sans" (AIranianSans). Designer credits in the file: Hadi Navid, Hooman Mehr (nevisa.com).
Source: A-Iranian-Sans1.zip, provided by the project owner (the archive is distributed via fontyab.com).

Usage in this project: served as the CSS family "IRANSans" (see the @font-face block in src/index.css)
and listed first in `font-sans` in tailwind.config.js.

Notes:
- Regular weight only. There is no Medium/Bold file, so browsers synthesise bold. Drop the other
  weights into this folder and extend the @font-face rules if they become available.
- This cut contains Persian/Arabic glyphs only (no Latin A-Z / 0-9), so Latin text falls back to
  the next family in the stack (Vazirmatn).
- Licensing/distribution of this font file is the responsibility of the project owner.
